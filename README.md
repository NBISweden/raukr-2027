**NBIS Summer School • Data Science With R**

This repo holds the workshop website and the workshop materials for RaukR 2027. This is a quarto website project. Topics are split into slides (presentations) and labs (tutorials). These are organized under the **slides** and **labs** directories respectively.

For contributors, please refer to the [CONTRIBUTORS.md](CONTRIBUTORS.md) file for guidelines on how to add or modify topics, preview and render documents, and submit pull requests.
